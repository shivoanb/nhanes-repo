# NHANES Health Data Analysis

This repository contains files used for course exercises exploring and analyzing NHANES health data in R.

## Repository Structure

- **data/** – Contains the NHANES dataset used for the analyses.
- **scripts/** – Contains R scripts for the current NHANES analysis, as well as reference scripts from previous course exercises.
- **reports/** – Contains R Markdown files and rendered reports produced for the course exercises.

The repository also includes the R project file used to organize and manage the analysis.
